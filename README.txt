DAKTELA CHATBOT DEMO — QUICK SETUP

FILES
- index.html
- daktela-logo.png
- screenshot-placeholder.svg

HOW TO REUSE
1. Add the customer's full-page website screenshot to this folder, for example:
   customer-screenshot.jpg

2. In index.html, replace:
   src="screenshot-placeholder.svg"
   with:
   src="customer-screenshot.jpg"

3. Replace every occurrence of:
   COMPANY_NAME
   with the customer's company name.

4. Replace the chatbot configuration:
   url
   daktelaAiChatId

5. Upload all files to the root of the GitHub repository.

GITHUB PAGES
Settings > Pages > Deploy from a branch > main > /(root)

NOTES
- The page intentionally blocks scrolling.
- The website screenshot is non-interactive.
- Only the Daktela chatbot remains interactive.
- For best results use a 1920 x 1080 or larger screenshot.
